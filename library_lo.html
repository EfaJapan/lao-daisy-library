ກ່ຽວກັບຫ້ອງສະໝຸດນີ້About this library

🎯 ເພື່ອຫຍັງ? / Purpose

ຫ້ອງສະໝຸດນີ້ ໃຫ້ເດັກທຸກຄົນ ອ່ານປຶ້ມດິຈິຕອນທີ່ມີສຽງໄດ້. ດຳເນີນງານພາຍໃຕ້ສົນທິສັນຍາ Marrakesh.This library operates under the Marrakesh Treaty to provide accessible digital books for children with reading difficulties, including those from disadvantaged backgrounds.

🧒 ສຳລັບໃຜ? / Target users

ເດັກທຸກຄົນ ທີ່ຕ້ອງການຄວາມຊ່ວຍເຫຼືອໃນການອ່ານ — ລວມທັງເດັກທີ່ມີຄວາມພິການ, ເດັກໃນຄອບຄົວທຸກຍາກ ແລະ ເດັກທີ່ຢູ່ໄກ.All children who need reading support — including children with disabilities, children from low-income families, and children in remote areas.

ວິທີອ່ານປຶ້ມ ໃນແອັບHow to read the books — reader app guide

1

ເອົາແອັບອ່ານປຶ້ມ ກ່ອນ (ຟຣີ)First, get a free reader app

ເລືອກແອັບ ຕາມເຄື່ອງຂອງເຈົ້າ.Choose the app for your device.

🤖AndroidColibrio ReaderGoogle Play ⬇ 🍎iPhone / iPadEasyReaderApp Store ⬇ 💻Windows PCThorium ReaderMicrosoft Store ⬇
2

ດາວໂຫຼດປຶ້ມDownload a book

  1. 👆ກົດປຸ່ມສີຂຽວ “⬇ ດາວໂຫຼດປຶ້ມ”Tap the green “Download” button
  2. 📥ປຶ້ມ (ໄຟລ໌ .epub) ຈະຖືກເກັບໄວ້ ໃນເຄື່ອງThe book (.epub file) is saved on your device
💡 iPhone (Safari): ກົດ ⬇ ຢູ່ແຖບດ້ານເທິງ → ກົດຊື່ໄຟລ໌.On iPhone (Safari): tap ⬇ in the address bar → tap the file name.
3

ເປີດປຶ້ມ ໃນແອັບOpen the book in the app

  1. 📁① ເປີດແອັບ Files (ຈັດການໄຟລ໌) → ໂຟນເດີ DownloadsOpen the Files app → Downloads folder
  2. 👆② ກົດໄຟລ໌ .epubTap the .epub file
  3. 📋③ ເລືອກ Colibrio ReaderChoose Colibrio Reader
  4. ✅④ ປຶ້ມເປີດແລ້ວ — ກົດ ▶ ແລ້ວຟັງ!The book opens — press ▶ and listen!
💡 ຖ້າບໍ່ເຫັນ Colibrio Reader: ເປີດແອັບ Colibrio Reader 1 ເທື່ອກ່ອນ ແລ້ວລອງໃໝ່. ຫຼື ເພີ່ມໄຟລ໌ຈາກໃນແອັບ.If Colibrio Reader is not shown: open the app once, then try again — or add the file from inside the app.
  1. 📁① ເປີດແອັບ Files (ໄຟລ໌) → Browse → On My iPhone → DownloadsOpen Files → Browse → On My iPhone → Downloads
  2. 👆② ກົດໄຟລ໌ .epub ຄ້າງໄວ້ → ກົດ Share (□↑)Press and hold the .epub file → tap Share (□↑)
  3. 📲③ ເລືອກ EasyReader (ຫຼື “Copy to EasyReader”)Choose EasyReader (or “Copy to EasyReader”)
  4. ✅④ ໃນ EasyReader ກົດ My Books → ເລືອກປຶ້ມ → ຟັງໄດ້ເລີຍ!In EasyReader, tap My Books → choose the book → listen!
💡 ຖ້າບໍ່ເຫັນ EasyReader: ເລື່ອນລາຍການ Share ໄປທາງຂວາ → ກົດ More → ເປີດ EasyReader.
💡 ຖ້າໄຟລ໌ບໍ່ຢູ່ Downloads: ລອງ iCloud Drive → Downloads ຫຼື ຊອກ “.epub”.Can’t see EasyReader? Scroll the Share list right → More → turn on EasyReader. File not in Downloads? Try iCloud Drive → Downloads, or search “.epub”.
  1. 💻① ເປີດ File Explorer → ໂຟນເດີ DownloadsOpen File Explorer → Downloads folder
  2. 📖② ເປີດ Thorium Reader → ລາກໄຟລ໌ .epub ມາວາງໃນແອັບOpen Thorium Reader → drag the .epub file into the app
  3. ✅③ ກົດໜ້າປົກປຶ້ມ → ກົດ ▶ ແລ້ວຟັງ!Click the book cover → press ▶ and listen!
💡 ຫຼື ກົດປຸ່ມ Import ໃນ Thorium ແລ້ວເລືອກໄຟລ໌ .epub.Or use Thorium’s Import button to choose the .epub file.
4
